Guide & Setup

1. Event Subscriber API

Managers handle event bindings through a custom createSubscriber() instance. Use getSubscriber() to register or unregister callbacks. 

// Register an event listener (returns an unbind function)
const unbind = mgr.selected.getSubscriber().bind("onChange", (selectedItems) => {
  console.log("Selected items changed:", selectedItems);
});

// Unregister when no longer needed
unbind();

// Or unregister using the handler reference directly
mgr.selected.getSubscriber().unbind("onChange", handlerRef);

2. Loading React Wrapper & CSS Bundle Mode

In bundle mode, import the unified CSS stylesheet directly in your React entrypoint or page alongside the component. 

// Import React component wrapper
import { CompositeSelect } from "composite-select/composite-select/react";

// Import the unified bundled CSS stylesheet
import "composite-select/dist/style.css";

export default function MySelect() {
  return (
    <CompositeSelect 
      selected-label="Select users..."
      options-show-filter
    />
  );
}

3. Loading React Wrapper & Separate CSS Requests Mode

Load CSS files individually, enabling modular styling or loading CSS via individual static <link> requests. 

// Import React component wrapper
import { CompositeSelect } from "composite-select/composite-select/react";

// Import modular CSS files for separate HTTP bundling / compilation
import "composite-select/floating-label-pattern.css";
import "composite-select/composition/selected-section/SelectedSectionManager.css";
import "composite-select/composition/options-section/OptionsSectionManager.css";

export default function MySelect() {
  return (
    <CompositeSelect 
      selected-label="Select users..."
      options-show-filter
    />
  );
}

4. Using ref to Access the Manager in React

The React wrapper is a forwardRef component that forwards the ref to the underlying <composite-select> element. The element exposes a getManager() method that returns the live CompositeManager instance — giving you imperative access to mgr.selected, mgr.options, and mgr.container. 

// 1. Import the element class so the ref type is correct
import { CompositeSelect } from "composite-select/composite-select/react";
import { CompositeSelect as CompositeSelectElement } from "composite-select/composite-select/composite-select";
import type { CompositeManager } from "composite-select";
import type { Item } from "composite-select/types";

// 2. Define your custom item shape (optional)
type MyItem = Item & { extra: string };

export default function MySelect() {
  // 3. Type the ref with the element class, parameterised with your item type
  const csRef = useRef<CompositeSelectElement<MyItem>>(null);

  // 4. Helper — safe getter, returns null before mount
  const getManager = (): CompositeManager<MyItem> | null =>
    csRef.current?.getManager<MyItem>() ?? null;

  useEffect(() => {
    const mgr = getManager();
    if (!mgr) return;

    // 5. Imperatively call manager methods
    mgr.selected.setValue("hello");
    mgr.options.setOptions([{ id: 1, label: "One" }]);
    mgr.container.setPosition("bottom");

    // 6. Subscribe to events imperatively
    const unsub = mgr.selected.getSubscriber().bind("onChange", (items) => {
      console.log("selected:", items);
    });

    return () => unsub(); // cleanup on unmount
  }, []);

  return (
    <CompositeSelect<MyItem> ref={csRef} selected-label="Pick..." />
  );
}

Key points:

  • Ref type is CompositeSelectElement<T> (the raw custom element class), not the React wrapper.
  • csRef.current?.getManager() returns CompositeManager<T> | null — null before mount.
  • Always guard with if (!mgr) return; — manager is created during connectedCallback, so it may not exist synchronously.
  • Use useLayoutEffect (instead of useEffect) when you need to bind events before the first paint, as the React wrapper itself does internally.
  • Always return the unsub() call from your effect to prevent memory leaks.
